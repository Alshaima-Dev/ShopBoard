# Product image sources

These are AI-generated illustrative product images created specifically for the ShopBoard demo with the built-in OpenAI image generation tool. They are not photographs of verified inventory and were not downloaded from a stock-photo site. No third-party reference photos were supplied. Prompts requested unbranded products without lettering, logos, people, or watermarks.

Final files are 1024 × 1024 JPEGs, resized with high-quality bicubic interpolation and saved at JPEG quality 90. The fallback SVG was authored for this project. Product names, IDs, categories, and prices are unchanged.

## Replacing an image

Replace the matching JPEG here using the same filename, or add a new local image and update its `image` path in `src/modules/products/products.data.ts`. Paths are relative to `public/`, for example `images/products/leather-tote-bag.jpg`. Update `imageAlt` to describe the replacement. Keep square framing and some empty space around the product. Use only your own images or images you have permission to reuse; record any new source and license here.
